## 🧠 Descripción

Este software POS permite:
- Ordenes de servicio dispositvos electronicos
- Registrar nuevas  y administrar productos
- Registrar ventas
- Gestionar clientes
- Ver reportes simples de ventas

👉 Ideal para pequeños negocios que necesitan un sistema fácil y ligero.


## Funcionalidades
- Factura Pos
- Inventario
- Informes
- Instalación en su computador, funciona sin internet
